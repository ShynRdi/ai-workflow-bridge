# AI Workflow Bridge 0.2.1 — Public Preview

This is the first open-source public preview of AI Workflow Bridge.

Highlights:

- guarded web-LLM ↔ local workflow loop;
- explicit Plan → Arm → Run → Change Course → Finish lifecycle;
- multi-provider web adapter registry;
- local roadmap/policy/approval enforcement;
- provider rate/account-safety pauses;
- sensitive-path protections and defense-in-depth output redaction;
- Apache-2.0 open-source project structure and CI.

## Important

This is pre-1.0 developer tooling and **not an OS sandbox**. Approved commands execute with the current user's permissions. Review `SECURITY.md` and `docs/SECURITY_MODEL.md` before use.

ChatGPT is the current stable regression target; other provider adapters are Beta or Experimental and should be supervised.
